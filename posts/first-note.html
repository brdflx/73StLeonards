First Note

The point of this blog (well, repository is probably the word, although it makes the whole thing sound more archival and intentional than it is) is to have somewhere to put the things I don’t want to put on my institutional website or institutional blog. This is not because those things will be scandalous, controversial, professionally inadvisable, etc. It is, much less interestingly, because I like categories. I like things to go where they are supposed to go. My academic blog is about academia, teaching, research, universities, and it would bother me, in a way I am aware is disproportionate but which awareness does not actually cure, to suddenly put there a post about a novel I’m reading, or a film I’ve watched, or an album I have been listening to repeatedly. Hence, this place.
The rule works in the other direction too. I am not going to write about academia here. There is already a box for that. This is the other box.
I don’t really expect anybody to read it, which is partly why it has the name it has: it’s one of my old addresses, because I needed a name and frankly there is something pleasing about turning an address at which I no longer live into an address at which some stray thoughts can live instead. Whether there will be enough of these thoughts to justify the real estate remains to be seen. I’m not even particularly sure what will end up here: books, films, music, things noticed, things remembered, probably things I thought I had forgotten until for some reason I hadn’t.
Also, there are no cookies here, no tracking, no analytics, no anything of that sort. It is simple HTML and CSS, hosted on GitHub, because I wanted it to be as simple as possible and, not incidentally, as close to free as possible. The cost of this place is therefore literally zero, except for the domain name, which is admittedly a small vanity project; but then, arguably, so is having a second box.
